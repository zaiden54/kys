# Requirements: НаРуки

**Defined:** 2026-08-28
**Core Value:** Пользователь может заранее и точно спланировать бюджет, зная сумму и дату ближайшей выплаты зарплаты на руки.

## v1 Requirements

Requirements for initial release. Each maps to roadmap phases.

### Аккаунты и синхронизация

- [ ] **AUTH-01**: Пользователь может зарегистрироваться и войти в аккаунт
- [ ] **AUTH-02**: Данные пользователя синхронизируются между устройствами через облако

### Оклад и график выплат

- [ ] **SAL-01**: Пользователь может указать оклад «грязными» и настроить даты выплат аванса и зарплаты (2 раза в месяц)
- [ ] **SAL-02**: Пользователь может изменить размер оклада; система хранит историю изменений оклада во времени
- [ ] **SAL-03**: При первом запуске пользователь может указать накопленный с начала года доход (YTD), если начинает пользоваться приложением не с января — иначе система явно предупреждает, что расчёт предполагает нулевой доход с начала года

### Налоговый расчёт (НДФЛ)

- [ ] **TAX-01**: Система рассчитывает НДФЛ по прогрессивной шкале 2025 года (13/15/18/20/22%) нарастающим итогом с начала календарного года
- [ ] **TAX-02**: Аванс и зарплата обрабатываются как отдельные события получения дохода, каждое облагается налогом относительно накопленной с начала года базы на момент выплаты

### Премии и компенсации

- [ ] **BON-01**: Пользователь может добавить разовую премию или компенсацию к конкретной дате выплаты
- [ ] **BON-02**: Премии и компенсации облагаются налогом через тот же кумулятивный механизм НДФЛ, что и обычная зарплата

### Отпуска и отпускные

- [ ] **VAC-01**: Пользователь может внести даты отпуска
- [ ] **VAC-02**: Система автоматически рассчитывает отпускные по формуле среднего дневного заработка за 12 месяцев (ст.139 ТК РФ, ÷29,3)
- [ ] **VAC-03**: Интерфейс явно указывает, что расчёт отпускных в v1 не учитывает исключаемые периоды (больничный, прошлый отпуск и т.п.) — это упрощённый расчёт

### Главный экран

- [ ] **HOME-01**: Главный экран показывает сумму и дату ближайшей выплаты
- [ ] **HOME-02**: Главный экран показывает годовую pie-диаграмму (грязными / налог / на руки) за текущий календарный год

### PWA

- [ ] **PWA-01**: Приложение устанавливается на домашний экран iPhone (манифест, иконки, standalone-режим)

## v2 Requirements

Deferred to future release. Tracked but not in current roadmap.

### Дифференциаторы (v1.x)

- **DIFF-01**: Индикатор приближения к следующей ступени НДФЛ
- **DIFF-02**: Разбивка грязными/налог/на руки для каждой отдельной выплаты, не только годовая
- **DIFF-03**: Планировщик отпуска (what-if) — подбор дат с предварительным показом суммы отпускных

### Расширения (v2+)

- **EXT-01**: Налоговые вычеты (на детей, имущественные и т.п.)
- **EXT-02**: Несколько источников дохода / работодателей одновременно
- **EXT-03**: Районный коэффициент / северная надбавка
- **EXT-04**: Offline-режим
- **EXT-05**: Push-уведомления о предстоящих выплатах
- **EXT-06**: Мульти-пользовательский/семейный совместный обзор доходов

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Налоговые вычеты (на детей, имущественные и т.п.) | Отдельный независимый движок правил, не меняет базовую модель расчёта — отложено на v2 |
| Несколько работодателей/источников дохода одновременно | v1 ограничен одним окладом на пользователя; объединение кумулятивных баз — усложнение для v2 |
| Offline-режим | Всегда требуется подключение к интернету; PWA-манифест нужен только для установки на экран |
| Сверка с фактическими расчётными листками работодателя | Приложение прогнозирует будущие выплаты, а не сверяет их постфактум с бухгалтерией |
| Районный коэффициент / северная надбавка (работа на Крайнем Севере) | Отдельная налоговая база с отдельными и часто меняющимися правилами (2025/2026) — требует второго параллельного налогового движка |
| Учёт исключаемых периодов при расчёте отпускных (больничный, предыдущий отпуск и т.п.) | v1 не ведёт историю отсутствий; расчёт отпускных — явно обозначенное упрощение, предполагающее отсутствие исключаемых периодов за 12 месяцев |
| Push-уведомления | Поддержка push в PWA на iOS ограничена и хрупка (только iOS 16.4+, только после установки на экран) |
| Импорт/парсинг расчётных листков от работодателя (1С, банковские выписки) | Превращает инструмент прогнозирования в инструмент бухгалтерской сверки — другой продукт |
