| Option | Description | Selected |

## Редактирование и удаление

| Option | Description | Selected |
|--------|-------------|----------|
| Да, полное редактирование | Сумма и дата премии редактируемы в любой момент, с пересчётом вперёд | ✓ |
| Только удаление и добавление заново | Проще реализовать, но два действия вместо одного | |

**User's choice:** Да, полное редактирование

| Option | Description | Selected |
|--------|-------------|----------|
| Да, полный список/история | Экран "Премии" со всеми записями, редактирование/удаление любой | ✓ |
| Нет, только влияющие на ближайшую выплату | Минимальный UI v1 | |

**User's choice:** Да, полный список/история

| Option | Description | Selected |
|--------|-------------|----------|
| Да, полный пересчёт вперёд | Как D-10 для YTD — любое изменение источника дохода пересчитывает кумулятивный налог | |
| Запретить удаление прошлых премий | Удалить можно только текущие/будущие; редактирование прошлых разрешено | ✓ |

**User's choice:** Запретить удаление прошлых премий
**Notes:** Уточняющий вопрос задан отдельно — является ли редактирование прошлой премии тоже ограниченным.

| Option | Description | Selected |
|--------|-------------|----------|
| Одинаковое ограничение: прошлые не трогать | И редактирование, и удаление прошлых премий запрещены | |
| Редактирование всегда разрешено, запрещено только удаление | Асимметрично, но позволяет исправить опечатки | ✓ |

**User's choice:** Редактирование всегда разрешено, запрещено только удаление
**Notes:** Итоговое правило: редактирование прошлой премии разрешено (с пересчётом вперёд), удаление прошлой премии запрещено.
