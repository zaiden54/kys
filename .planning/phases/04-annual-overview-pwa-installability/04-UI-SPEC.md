## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 |
| Label / Heading | 14–18px (text-sm, text-lg) | 600 (semibold) | 1.2 |
| Display | 24–32px (text-2xl, text-3xl) | 600 (semibold) | 1.2 |

**Font Weight Scale (2 total):**
- 400 (regular) — body text only
- 600 (semibold) — all labels, headings, interactive elements, and display

**Tailwind classes (Phase 4 additions):**
- Pie-chart legend: `text-sm` (14px, regular) — labels for pie segments «Грязными», «Налог», «На руки»
- Pie-chart value labels (within chart): `text-sm font-semibold` (14px, semibold) for ruble amounts and percentages
- Install banner heading: `text-lg font-semibold` (18px, semibold) or smaller depending on banner size
- Standalone re-login hint: `text-sm` (14px, regular) for contextual help text

**Rationale (inherited from Phase 1–3):**
- 14px body is readable on mobile (Phase 1 requirement: PWA on iPhone).
- 1.5 line-height on body ensures readability; 1.2 on headings matches Russian typography conventions.
- Semibold (600) used for all interactive labels, headings, and chart legend to create clear visual hierarchy.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | white (#ffffff) light / #0a0a0a dark | Page background, card backgrounds (light/dark mode toggle via `prefers-color-scheme`) |
| Secondary (30%) | zinc-100 light / zinc-900 dark | Card borders, disabled states, secondary text, pie-chart legend background |
| Accent (10%) | zinc-900 (actions/PWA) / red-600 (destructive) | Primary CTA buttons, form labels, destructive actions, PWA app icon background |
| Destructive | red-600 | Error messages, delete confirmations, validation feedback |
| Pie-chart colors | white/zinc-900 (dominant), blue-600, green-600, amber-600 (for pie segments) | Gross (one color), Tax (one color), Net (one color) — distinct within chart |
| Supporting | zinc-400, zinc-500, zinc-600 | Secondary text, hints, disabled states |

**Color-specific rules:**

1. **Pie-chart primary segments:** Use three distinct colors for Gross, Tax, and Net:
   - Gross («Грязными»): Tailwind `blue-600` (or closest blue-tone in palette)
   - Tax («Налог»): Tailwind `red-600` (warning/tax semantic)
   - Net («На руки»): Tailwind `green-600` (positive/gain semantic)
   
   Each segment must be distinguishable in both light and dark mode; colors are chosen to meet WCAG AA contrast against white/dark backgrounds.

2. **Pie-chart legend:** Legend rendered below chart using `text-sm` labels. Each legend item shows colored dot + label text. Legend background matches card background (white in light mode, zinc-900 in dark mode).

3. **Pie-chart container (card):** `rounded border border-zinc-300 p-4 gap-4` — matches Phase 1–2 card styling.

4. **Annual overview section heading:** `text-lg font-semibold` in zinc-900 (light) / zinc-100 (dark) — placed above the pie chart on the home screen.

5. **Install instruction banner (home screen):** 
   - Background: `bg-zinc-100` (light) / `bg-zinc-800` (dark)
   - Text: `text-sm text-zinc-900` (light) / `text-zinc-100` (dark)
   - Border: `border-l-4 border-zinc-900` (accent-colored left edge)
   - Dismiss button: `text-zinc-500 hover:text-zinc-900` (subtle, secondary)
   - Visible when: `navigator.standalone !== true` AND `matchMedia('(display-mode: standalone)').matches === false`
   - Hidden when: Standalone mode detected
   - Copy: "Поделиться → На экран «Домой»" or similar per phase DECISIONS

6. **Login screen standalone re-login hint:**
   - Background: `bg-blue-50` (light) / `bg-blue-900/30` (dark) — gentle, informational
   - Text: `text-sm text-blue-600` (light) / `text-blue-300` (dark)
   - Icon: info icon (from existing icon set or system emoji)
   - Copy: "похоже, это первый запуск с домашнего экрана — войдите ещё раз"
   - Visible when: `navigator.standalone === true` AND user is unauthenticated (no session)

7. **Dark mode support:**
   - Light mode: CSS `@media (prefers-color-scheme: light)` (default)
   - Dark mode: CSS `@media (prefers-color-scheme: dark)`
   - No forced dark mode; iOS Safari respects system setting.

**Accent reserved for:**
- Primary CTA buttons ("Добавить отпуск", "Сохранить", "Подтвердить", etc. — inherited from Phase 1–3)
- PWA app icon background (#18181b = zinc-900)
- Form field labels (required/descriptive text — inherited from Phase 1–3)
- Active form input focus outline (if added — inherited from Phase 1–3)
- **NOT** reserved for: All interactive elements, all links, hover states (use subtle color shifts instead)

| persistent | Banner re-appears on new session if not installed | ✅ covered | If user dismisses banner but does not install the app, and then returns to the app in a fresh browser tab (new session, localStorage intact), the banner remains hidden per the dismissed flag.
