| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | `src/lib/session.ts` | high | mitigate | `requireUserId()` derives the id exclusively from `auth.api.getSession({ headers })`; no exported function accepts a client-supplied user id.
